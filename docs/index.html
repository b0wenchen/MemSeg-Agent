THE IDEA

Learning through
the evolution of memory.

New scanners, institutions, and patient populations bring new segmentation challenges. We represent adaptation knowledge in an explicit memory state that can grow and change throughout deployment.

Our static, few-shot, and working memories share the native SAM2 memory interface. A read–write controller retrieves relevant experience, composes it with stable task priors, and consolidates new feedback while the backbone stays fixed.

Explore the methodology

METHOD

One backbone. Three kinds of memory.

Our default backbone is SAM2.1 Hiera-Tiny. We also evaluate static memory with frozen MedSAM2.

S

Static memory

We learn task-specific pseudo-image and pseudo-mask prototypes through the frozen observation-to-memory pathway. These memories provide a persistent supervised prior.

Supervised construction
F

Few-shot memory

We encode labeled support examples into reusable memories. Similarity-based retrieval selects relevant examples without additional optimization.

Support-based inference
W

Working memory

We encode corrected image–mask pairs after prediction. New observations expand memory; similar observations update an existing entry through delta consolidation.

Feedback-driven adaptation
The read–write controller

Frozen DINOv3 features rank few-shot and working memories by cosine similarity. The controller combines retrieved entries with static memory, then appends or consolidates corrections for future cases.

Predict first. Learn from feedback for the next case.

  1. Retrieve & predictUse only memories available before the current case.
  2. Evaluate & correctScore the prediction, then receive a corrected annotation.
  3. Write & continueUpdate working memory to guide subsequent cases.

Our retrospective experiments simulate clinician corrections with ground truth when Dice < 0.5. Corrections cannot improve the score of the same case. Memory novelty uses a similarity threshold of 0.95. Read–write policy

FEDERATED LEARNING

Collaborate through compact memory.

Task-specific memory exchange with a shared, frozen foundation model.

In our four-site FedAvg experiment, clients optimize static-memory variables locally and the server aggregates them. Images and annotations stay at each site. Our Static Memory (SAM2) – FL results remain competitive across CHAOS, ACDC, and CAMUS.

Our paper reports a 74.3× communication reduction for compact memory exchange. The payload comparison below distinguishes the encoded memory representation from the learnable pseudo-observations used to construct it.

ABLATION STUDIES

What makes memory useful?

Task relevance, complementary memory sources, and the amount of retrieved experience.

Meaningful content matters.

Our memory-validity study compares pseudo-observations, direct tokens, and real examples with unrelated, shuffled, random, and empty memories. Task-aligned representations produce meaningful predictions; the negative controls yield near-zero Dice.

Direct tokens achieve the highest Dice in this study. Pseudo-observations preserve the common observation-to-memory pathway used throughout our framework.

It is a fixed external cohort, not the complete official test partition, and is excluded from training and validation. We predict slice-wise and evaluate reconstructed volumes.
